# 数据结构考研理论与核心考点

> 适用对象：以考研、课程考试和理论复习为目标的学生。本文档作为课程 AI 助教的基础事实资料，回答时应结合题目条件，不可把复杂度结论脱离具体实现。

## 1. 复杂度分析

- 时间复杂度描述输入规模增长时基本操作次数的数量级，常用大 O 表示上界。
- 空间复杂度包含算法运行过程中额外使用的辅助空间。递归调用栈也要计入辅助空间。
- 顺序查找平均和最坏时间复杂度通常为 O(n)；有序顺序表上的二分查找时间复杂度为 O(log n)。
- 不能只看到两层循环就断定为 O(n²)，循环变量的增长方式和提前终止条件都会影响结论。

## 2. 线性表

### 顺序表

顺序表使用连续存储空间，支持 O(1) 随机访问。已知位置的插入和删除通常需要移动元素，最坏时间复杂度为 O(n)。动态数组扩容时通常申请更大的连续空间并搬移元素，单次扩容为 O(n)，采用倍增策略时连续尾插的均摊复杂度可视为 O(1)。

### 链表

链表结点不要求物理连续。已知结点位置后插入、删除可在 O(1) 完成，但按下标查找需要 O(n)。单链表只能沿后继方向访问；双链表同时保留前驱和后继引用，便于双向遍历与删除。

## 3. 栈、队列和递归

- 栈遵循后进先出，典型应用包括括号匹配、表达式求值、函数调用和深度优先搜索。
- 队列遵循先进先出，典型应用包括层序遍历、广度优先搜索和任务调度。
- 循环队列常采用预留一个空位区分队空和队满。若数组长度为 m，则队满条件可写为 `(rear + 1) % m == front`。
- 递归必须包含终止条件，并保证问题规模向终止条件收敛。递归可通过显式栈改写为迭代。

## 4. 串与模式匹配

朴素模式匹配最坏时间复杂度可达到 O(nm)。KMP 算法利用模式串前缀与后缀信息，主串指针不回退，整体时间复杂度为 O(n+m)。理解 next 数组时，应明确教材采用的是下标从 0 还是从 1 开始的定义，不同定义的数值可能不同，但失配后的跳转思想一致。

## 5. 树与二叉树

- 含 n 个结点的树有 n-1 条边。
- 二叉树第 i 层最多有 2^(i-1) 个结点（根为第 1 层）。
- 非空二叉树中，度为 0 的结点数 n0 与度为 2 的结点数 n2 满足 `n0 = n2 + 1`。
- 前序遍历为根、左、右；中序遍历为左、根、右；后序遍历为左、右、根；层序遍历使用队列。
- 仅凭前序和后序一般不能唯一确定一棵二叉树；前序加中序或后序加中序，在结点值互异时可以唯一确定。

### 二叉搜索树

二叉搜索树满足左子树关键字小于根、右子树关键字大于根（重复关键字规则需由实现约定）。操作复杂度与树高 h 有关，为 O(h)。平衡时 h≈log n，退化为链时 h≈n。

### AVL 树与红黑树

AVL 树要求任意结点左右子树高度差绝对值不超过 1，查询稳定，但更新可能需要旋转维护严格平衡。红黑树通过颜色约束保证从根到叶子的最长路径不超过最短路径的两倍，使查找、插入和删除保持 O(log n)。红黑树平衡要求相对宽松，因此常用于需要频繁更新的有序映射和集合。

### B 树与 B+树

B 树是多路平衡查找树，结点可保存多个关键字和子指针，用于减少外存访问次数。B+树的非叶结点主要承担索引作用，数据记录集中在叶结点，叶结点按关键字顺序链接，更适合数据库索引和范围查询。

## 6. 图

- 图可用邻接矩阵或邻接表存储。邻接矩阵适合稠密图，判断边是否存在为 O(1)；邻接表适合稀疏图，空间通常为 O(V+E)。
- BFS 使用队列，在无权图中可求单源最短路径；DFS 使用递归或显式栈，常用于连通性、拓扑相关处理和回溯。
- Dijkstra 算法要求边权非负。存在负权边时不能直接使用 Dijkstra。
- Floyd 算法可求多源最短路径，典型时间复杂度为 O(V³)。
- 拓扑排序只适用于有向无环图。若无法输出全部顶点，说明图中存在有向环。
- 最小生成树适用于连通无向带权图。Prim 更偏向按顶点扩展，Kruskal 按边权排序并使用并查集避免成环。

## 7. 查找与散列表

散列表通过散列函数把关键字映射到桶位置。常见冲突处理方法包括开放定址和链地址法。装载因子越高，冲突通常越多。散列表平均查找可接近 O(1)，但最坏情况仍可能达到 O(n)，不能表述为绝对 O(1)。

## 8. 排序

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 直接插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 简单选择排序 | O(n²) | O(n²) | O(1) | 不稳定 |
| 快速排序 | O(n log n) | O(n²) | 与递归深度有关 | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |

快速排序的一趟划分会把枢轴放到最终位置，但左右两侧内部不一定有序。归并排序适合外部排序和需要稳定性的场景。堆排序能保证 O(n log n) 最坏时间，但访问局部性和常数因素可能影响实际性能。

## 9. 答题检查清单

1. 先判断题目讨论的是逻辑结构、存储结构还是具体算法。
2. 写复杂度时注明平均、最坏、均摊以及实现前提。
3. 图算法先检查有向/无向、是否连通、边权是否为负。
4. 树题明确空树、重复关键字和高度定义。
5. 排序题关注每一趟的状态、稳定性、原地性和适用数据分布。
